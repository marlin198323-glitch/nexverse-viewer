# Alpha.110 – Firestorm original wearable asset parser, LLUDP download and F9 evidence

Source baseline OGL develop-current 22f78a4934a91208327ae47d3e5c554315100526, OpenGenesisLINK Server main 2b7c19c9396eb2f75fd60a41a33a05655909da6b, Firestorm_7.2.4 indra/llappearance/llwearable.cpp importStream, llavatarappearancedefines.h/cpp, scripts/messages/message_template.msg.

- Real v1 LLWearable text import: header + definition version1, name/description, legacy permissions0 and sale_info0, type0..16, <=1000 unique finite visual parameter weights, <=100 unique local TextureEntry UUIDs. Maximum 2MiB, max 8192 lines / 2047 chars each. No fallback from empty flags to shape0. Legacy version24 migration and live user asset access remain unverified.
- Protocol Low153 TransferRequest (Source2, Channel2, owner-inventory Asset UUID and Clothing5/Bodypart13 type) triggered by explicit F9 click. Shared packet delivery from simulator Low154 TransferInfo / High17 TransferPacket is routed into an independent epoch-bound typed WearableTransferInbox, out-of-order assembled with bounded 2MiB and duplicate checks. Only actual parent COF owned originals from authenticated FetchInventory2 and current COF Server version may be used. One request at a time, <=16 assets, 12-second timeout per item, no automatic retry on uncertain outcome.
- Firestorm ETextureIndex TEX_NUM_INDICES=45; eleven baked output TE index values 8,9,10,11,19,20,40..44. Actual source associations LLAvatarAppearanceDictionary::BakedTextures map local tex IDs to 11 bake groups; the F9 status counts reference IDs only. No JPEG2000 local-pixel decode, alpha mask compositing, baked texture upload or GPU Appearance changes.
- GUI: F9 real left-column Asset laden button and status under COF/Appearance, no overlap with right COF batch. Shows decoded params/textures and Head/Upper/Lower local source references, explicitly unbaked. All preview is invalidated on COF change/region transition. Debug tests simulate format and packets but **no live-authenticated NexVerse inworld wear** was possible without user credentials.
- Tests firestorm_wearable_asset_tests.cpp, firestorm_wearable_transfer_tests.cpp and revised outfit_gallery_layout_tests.cpp, plus all existing CTest/Python and NVIDIA GL3.3 GUI smoke. Verify GitHub SHAs and server baseline before pushing.
- Still required for true Firestorm Outfit Wear: JPEG2000 texture resource fetch/decode; TexLayer XML masks, blending, baking; AgentCachedTexture/AgentSetAppearance, true GPU-avatar skin/attachments, complete COF transactional replacement and rollback, authenticated NexVerse real-grid confirmation.
