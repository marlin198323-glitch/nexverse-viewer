## Universelle Hardware-/Plattformpolitik

**Nicht auf RTX 4070 SUPER abgestimmt.** Eine NVIDIA-, AMD-, Intel- oder Software-OpenGL-Implementierung verwendet dieselben Szenenplanung-/Renderergrenzen. Schonendere Grafikprofile bevorzugen weniger residente Meshes. Der Ressourcenpfad berücksichtigt Bytebudget, Staging, Request-Pacing, LOD-/Distanzpriorität, Evictions und echte GL-Treiberantworten. Eine obere Slotanzahl allein reserviert **keinen** VRAM; die Treiber dürfen trotz gültigem Slot bei fehlendem Speicher den Upload ablehnen. Bei solchen Problemen müssen niedrigere Detail-LOD und budgetiertes Nachladen greifen. Auf leistungsstärkeren GPUs sollen im Detailprofil bis zu 384 verschiedene Meshes möglich sein, **solange** die bestehenden Budgetgrenzen dies erlauben.

Der Renderer ist weiterhin kein garantierter 100-%-Firestorm-Grafikklon. Für alle Nutzer müssen langfristig Auflösung/LOD/VRAM-/CPU-Last und Einstellungen abgestuft werden, die Original-Firestorm-Materialpipeline einschließlich Legacy normal/specular und moderner RenderMaterials/PBR, Alpha-Transparenz, korrekte UVs, Gelände-Schichtmischung, Schatten/Beleuchtung und vollständiges Outfit an einem echten Grid verifiziert werden. Die vorliegende Reparatur entfernt eine objektive Kapazitätsinkonsistenz und verbessert die Qualitätsevidenz; sie belegt allein noch keine perfekte optische Übereinstimmung.
