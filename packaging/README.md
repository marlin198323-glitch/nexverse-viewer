# Packaging

Target packages:

- Linux x64: AppImage or equivalent desktop package
- Windows x64: installer and portable test build
- macOS x64/ARM64: .app bundle and DMG

Product name:

```text
OpenGenesisLINK Viewer
```

Primary grid/platform:

```text
NexVerse
```

Packaging must use the canonical artwork described in `assets/branding/README.md`.

Phase 0 only prepares the structure. Installable alpha artifacts are produced after the protocol bootstrap is stable enough for real-grid testing.
